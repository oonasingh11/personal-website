Oons Drone

I am actually building a video game!

Hello all. Welcome and welcome back.

Somehow, I’m building a game.

I did say Oons Drone was a simulator. Still, I don’t think I figured out that a simulator you can play with that’s interactive is, for many intents and purposes, a video game - and perhaps the key to this puzzle is in the graphics, so disregard my previous post on my newest project.

I’ve decided to use Unity (right now) because it’s more user-friendly, but I’m curious about User Friendly given that I don’t know any C#. But listen, get busy learning or dying, guys - so I guess I’m learning C# for this project.

I actually was contemplating between Unreal engine and Unity - but I had previously tried to use Unreal to build something, and I did not understand what was going on (candidly I still don’t understand what is going on).

In the end, I went with Unity to build my drone game.

After downloading it, the first thing you do is pretty user-friendly: select the project type you want based on your requirements. I picked 3D (Built-In Render Pipeline), a shell to build your own 3D project.

I set up my version control as well, which is pretty straightforward. (Version control is a programming tool that allows you to save versions of your project to roll back or push changes. Version control systems are also commonly used when working on a team, so people will often create branches for their own set of changes).

So, what do the next steps look like? I should import all the assets I will need for this drone simulator. However, I’m more concerned with immediately familiarising myself with my new bestie, Unity, because I don’t have a clue about what this application can do or how it works.

That’s all for today, folks, I kept it short to balance out my last, much less pithy newsletter.
